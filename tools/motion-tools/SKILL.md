# Motion tool provider contract

This is not a runnable provider. Read [provider contracts](references/contracts.md) and [quality checks](references/quality-checks.md). These contracts travel with this directory. The upstream kit supplies diagnostics and renderer examples only; it is not required at a sibling installed path to read this provider contract. Upstream-derived guidance remains Copyright (c) 2026 echris6 under [MIT permission and warranty notice](LICENSE.upstream-mit); original provider design has no chosen license.

Implement the declared commands under Curator's audited provider contract. Do not add placeholders that return success. The executor owns machine results. Scene code must never select checks or access API keys. Each operation records its candidate hash, pinned input hashes, exact provider/toolchain/backend, tier, decoded artifact and evidence coverage. Paid operations require actual approval, delegated ceiling, budget, idempotency key and receipt. Machine numbers do not prove taste or human comprehension.

At review the critic independently re-measures candidate evidence with a local shell, ffmpeg and kit diagnostics; it cannot invoke kernel tool roles. At final export rerun all numeric checks in every size. Refuse unavailable inputs, incomplete frames or missing evidence. The local contracts state schema/distribution prerequisites and gaps 1–12. Kernel reports are excluded from critic packets; the lead compares independent critic numbers with kernel results afterwards in the ledger.
