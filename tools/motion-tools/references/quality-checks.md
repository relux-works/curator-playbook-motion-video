# Quality check sets

These are a draft §6.12 design, with actual role/tool homes. The package example task-board.config.json illustrates named local definitions; it is not needed to read this installed contract. No executable providers ship here. §6.12 only gates Change Request delivery and passes inline work without evidence. This film uses tool states, not delivery.checks-passed. Generic artifact check-set acceptance is package gap 7.

The ignored `x-pc3.files.input_graph` declares facts, storyboard, shared-piece, scene, audio and export content dependencies. Its selectors are illustrative until §5.5 adopts the exact grammar; facts supersession must invalidate the downstream chain.

Numeric threshold params live only in `x-pc3.quality_params` until §6.14 adopts number/string params and tool settings. Current native params tune retry counts, WIP and deadlines only. The diagnostic basis is explicit in frame_diff_basis; native_frame_diff_threshold is null until calibrated and declared. Never apply the 10 fps value to adjacent 60 fps frames. An operator must not silently treat ignored x data as authoritative settings.

| Set / owner | Bar | Method and limitation |
| --- | --- | --- |
| motion-test / test-render | Decode a five-second 1080p60 test before real build | Verify frames, clock seeking, local assets, fonts, encode and decode; test content is a setup fixture. |
| motion-frozen / frozen-loudness | Total frozen ≤1 s × duration/30; maximum still stretch ≤0.5 s, no end-card exception | Native-frame adjacent luma difference, declare a calibrated native threshold; 0.35 is diagnostic only at 10 fps on 320-wide gray luma, YAVG of tblend difference, contiguous-run accounting. Report scale/fps/threshold and actual coverage. Fast noise cannot stand in for meaningful motion; critic also watches. |
| frame-one-finished / critic | Frame 0 is a finished composition | Vision judgement; a rendered frame existing is not a composition test. |
| motion-contrast / contrast + critic | Every text target ≥4.5:1; no collision or text passing through other text | Decoded pixel luminance and per-frame text/background masks; swept geometry where available; include transitions. Busy backgrounds need backing. Unknown masks require critic inspection, never automatic pass. |
| motion-brand / brand-colour | 3D decoded background matches brand RGB within a declared default ±3 per 8-bit channel | Measure selected decoded regions through capture/encode against tokens. Record region, colour space and codec. Compare the mean of flat interior sRGB patches per channel on each decoded final size. The small tolerance accounts for capture/codec quantization, not tone-map drift. Declare patch/codec and actual error; critic rejects visible mismatch even inside tolerance. Operator may change the allowance before the run with a reason, never silently after failure. |
| motion-audio / frozen-loudness + critic | Calm default −16 LUFS ±1; punchy −14 LUFS ±1; true peak ≤−1 dBFS, no clipping, steady short-term level | ebur128 integrated/short-term/LRA/peak. Dynamics target about ≥3 LU energetic, 1.5–3 LU calm. Comfort and genre fit need listening. Style, target and ±1 comparison tolerance are declared package/operator choices, not prompt thresholds; they can be changed before the run with a reason. |
| motion-audio / decoded stems | Effect full-band peak ≤ local music peak; intended in-band clarity about +3.5 dB; 2–8 kHz lift ≤4 dB | Compare effect and music-only stems over declared windows; report 50 ms peak and 150 ms body. Separate full-band cap from in-band lift. Silence or an infeasible pair needs remix/removal, not waived evidence. |
| motion-determinism / determinism | Exact decoded-pixel equality for same times from different seek orders | Pin fonts, dependencies, seed, GPU/backend and sizes. Test endpoints, handoffs, fastest moves and selected random frames; report exact times. It cannot prove every animated expression is a pure function or every backend reproduces pixels. |
| motion-seams / seams + critic | Carried object has exact identity and projected pixel rectangle on both sides | Compare shared pose/anchor coordinates and decoded frames at every cut in every size. The entire frame can change while the carried object stays exact. |
| sound-off-comprehension / critic | A first-time viewer can state the purpose and CTA on mute | Critic assessment only. Report whether a real first-time human watched it; do not claim an audience test that did not happen. |
| reference-strength / critic | Holds up beside supplied references | Creative assessment only, with named timestamped comparisons. With no supplied videos, use written kit benchmarks and disclose the narrower basis. |
| truth / critic + future source audit | Numbers, names and claims only from facts; no fake results; concepts labelled | Facts-to-screen mapping and complete rendered inspection. Current schema cannot pin file content or enforce every claim; gaps 1 and 8. |
| motion-exports / delivery-audit + critic | Every size MP4 1080p60, music-only version, complete frames, same duration, final contact sheet | Every deliverable explicitly runs metrics (frozen/loudness and decoded stem comparison), contrast, colour and determinism after final-render/music-only/sheets, then delivery-audit and a fresh critic. Failures enter lead-owned rework; the parent film detects it through children.any-in, repairs sources and reruns all sizes. Measured and creative evidence must bind the new final encoded size; presence-only freshness is gaps 1 and 7. Include poster, source, generation/critic ledgers, measured results and human-check note. No publishing step. |

Human checks are an explicit report category: final viewing on target devices, audio comfort on actual speakers, actual first-time-viewer comprehension, final brand and license ownership. They are not fabricated machine results. The brief delegates production choices, not the right to invent evidence. A critic may assess taste autonomously; material unverified quality means not-shipped, while device preference notes may accompany a passed draft film.

Fresh measurement reports are scoped to candidate digest and size by the role/provider contract, not a current kernel artifact guard. Native passes are tool.passed/tool.failed. Tool failures cannot reach accepted or bypass review. A terminal child with failure means parent failure; the lead's routing field remains false.

The [local provider contracts](contracts.md) define manifest handoff and bounded stdout. Critics measure alone without kernel reports; the lead compares their independently recorded numbers with kernel results afterwards in the ledger.
