# Precedence and limits

The task brief fixes the package shape and honesty. The supplied prompt fixes this process. The kit overrides generic defaults. The unmodified kit remains MIT; kit-derived instructions retain its notice. The prompt's licence is not stated upstream; it is reproduced with attribution and treated as MIT for caution.

| Difference | Package decision |
| --- | --- |
| Kit starts with a brief; prompt says a five-second test first | Intake is input loading only. A setup fixture tests the renderer before study/planning; the production brief and storyboard follow reference study. |
| Kit says stop at cosmetic gains; prompt requires every check | Cosmetic gains never allow a failed check to ship. Finite loops end not-shipped. |
| Kit frozen maximum is 0.6 seconds with final CTA exception | Use 0.5 seconds with no CTA exception and 1 second per 30 seconds total. |
| Kit contrast exempts transitional fades | The task's all-text 4.5:1 floor applies throughout. Reveal text with backing or masks instead of unreadable fades. |
| Kit effect examples exceed local music and even use a +6 dB peak cap | Use full-band effect peak ≤ local music peak; an in-band clarity target is a separate measurement. Revise sources if both cannot hold. |
| Upstream review packets include a previous critic report | Round packet: candidate, brief with facts, references. Round ≥2 verification packet adds only the previous critic's own report. Judge blind first, then mark all prior items FIXED / PARTLY / STILL PRESENT and hunt regressions. Kernel measurement reports are excluded. The critic measures alone; the lead compares critic and kernel numbers afterwards in critic-round.kernel_comparison and the film ledger. The previous critic report remains critic-authored, without the lead comparison. Verification is required now; kernel allowlist enforcement is gap 6. |
| Prompt says clone github.com/echris6/motion | The kit is already vendored at skills/business-motion-film/; do not clone. Read its SKILL.md and the references at their named steps. The original prompt line is preserved for traceability and overridden here. Installed dependency addressing remains gap 9. |
| Kit critic-prompt templates invite builder context | Fill kit critic-prompt slots only from the brief, references and previous critic report. Leave the component “replaces / why rejected” and verification “timings moved / new section map” slots empty. Never carry builder claims or kernel reports through those slots. |
| Upstream component lab uses a CDN | Copy to the work artifact and bind pinned local dependencies. Vendor stays byte-identical. |
| Upstream kit has a lab and renderer CLI examples | HyperFrames is the intended reference renderer. The kit has no renderer implementation or Curator manifest. Pin/vendor HyperFrames and dependencies inside a future audited provider; no unpinned npx fetch. Gap 9. |
| Upstream contact sheet produces one tile; frozen script samples at 10 fps | Paginate sheets. frame_diff_threshold=0.35 is diagnostic only: 10 fps, 320-wide luma, YAVG of tblend difference. Native 60 fps threshold remains unset until calibrated and declared with a rationale; never reuse 0.35 unchanged. Use native-frame measurement providers for exhaustive results. |
| Upstream mixer has a fixed 40-second cut and local gain defaults | Adapt only a work copy, with actual duration, beat map and strict caps. |
| Repeated frames depend on the GPU and rasterizer | Pin versions, fonts, backend, sizes and seed. Evidence applies to that environment and tested frames only. |
| Prompt says steady/comfortable; kit suggests −14 LUFS punchy and about −16 calm | Use calm −16 LUFS as the safe illustrative default; punchy style uses −14. Package ±1 LU tolerance is declared for repeatable comparisons, not attributed to the prompt. Operator may change loudness_style, target_lufs, punchy_target_lufs and lufs_tolerance before the run with a reason; no automatic relaxation on failure. Comfort is still judged by listening. |
| Prompt says brand match; kit measures capture/encode shifts without a tolerance | Default brand_rgb_tolerance=3 in 8-bit sRGB: each channel's absolute mean decoded patch error ≤3. Small capture/codec quantization is expected; tone mapping or perceptually wrong colour still fails critic review. Operator may change the declared tolerance before the run with a rationale; never silently after failure. Record flat interior patch, colour space, codec and decoded final size. |
| Prompt says keep going until every check passes | critic_rounds=none is faithful. The away-mode default is 5 return passes to bound unattended resource use. Reaching the bound ends not-shipped; it never authorizes shipping unmet quality. Other rework limits remain operator-tunable through §7.3. |
